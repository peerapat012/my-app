# Money Tracker — Domain Context

ภาษากลาง (ubiquitous language) ของโปรเจกต์ ใช้คำเหล่านี้ให้ตรงกันทั้งในโค้ด, UI และเอกสาร

| คำ (โค้ด) | UI (ไทย) | ความหมาย |
|---|---|---|
| `User` | ผู้ใช้ | เจ้าของบัญชี (Better Auth) ข้อมูลทุกอย่างแยกตาม `userId` |
| `Transaction` | รายการ | การรับ/จ่ายเงินหนึ่งครั้ง: ประเภท, จำนวนเงิน, หมวด, บันทึก, วันที่ |
| `TransactionType` | ประเภท | `income` (รายรับ) หรือ `expense` (รายจ่าย) |
| `Category` | หมวดหมู่ | หมวดของรายการ ผูกกับประเภทเดียว (`income`/`expense`) |
| Archived category | (ซ่อน) | หมวดที่ถูก "ลบ" = soft delete (`deletedAt`) — ไม่แสดงในตัวเลือก แต่รายการเก่ายังแสดงชื่อเดิม |
| Default categories | หมวดตั้งต้น | ชุดหมวดที่ seed ให้ผู้ใช้ใหม่ตอนสมัคร |
| `RecurringRule` | รายการประจำ | แม่แบบรายการที่เกิดซ้ำ **ทุกเดือน** ณ `dayOfMonth` |
| Pending occurrence | รอยืนยัน | รายการประจำที่ถึงกำหนดในเดือนนั้นแล้วแต่ผู้ใช้ยังไม่ยืนยัน/ข้าม — **คำนวณสด ไม่ได้เก็บเป็นแถว** |
| `RecurringOccurrence` | — | บันทึกว่ารายการประจำของเดือน X ถูก `confirmed` (สร้าง Transaction แล้ว) หรือ `skipped` |
| Month | เดือน | ช่วงที่กำลังดู รูปแบบ `YYYY-MM` (ค.ศ.) |
| Monthly summary | ภาพรวม | รายรับ, รายจ่าย, คงเหลือ, % ใช้ไป, รายจ่ายตามหมวด ของเดือนที่เลือก |

## กฎหลัก (invariants)

- จำนวนเงิน > 0 เสมอ เครื่องหมายมาจาก `type` ไม่ใช่ค่าติดลบ
- หมวดของรายการต้องมี `type` ตรงกับรายการ
- ชื่อหมวดไม่ซ้ำภายใน (user, type) เฉพาะที่ยังไม่ถูก archive
- วันที่ทั้งหมดตีความใน timezone **Asia/Bangkok**; แสดงปี **ค.ศ.**, สกุลเงิน **฿ (THB)**
- ยอดสรุปนับเฉพาะ Transaction จริง — **ไม่นับ** รายการรอยืนยัน
- รายการประจำตั้ง `dayOfMonth` = 1–31; ถ้าเดือนนั้นไม่มีวันนั้น ใช้ **วันสุดท้ายของเดือน**
